# MILI AI 플랫폼

Figma Make에서 내보낸 화면을 Vite + React 기반으로 정리한 MILI AI 학습
플랫폼입니다. 홈, VOD 목록과 상세, 프로젝트 목록과 상세, 마이페이지,
모바일 내비게이션 및 주요 버튼 인터랙션을 포함합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## 프로덕션 빌드

```bash
npm run build
```

빌드 결과는 `dist` 디렉터리에 생성됩니다.

## Vercel

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
